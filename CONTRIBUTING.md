# Contributing

This repository does not accept contributions. Oudepode is the sole operator of the Hapax operating environment by constitutional axiom (`single_user`, weight 100); the architecture forecloses contributor onboarding at the structural level.

## Why

Hapax is research infrastructure for one operator's externalised executive function. It is not a product, not a service, and not a library to extend. The refusal is the artifact: see the Refusal Brief at https://hapax.weblog.lol/refusal-brief.

## What this means in practice

- Issues are disabled; do not open them on a fork.
- Pull requests are auto-closed by `.github/workflows/`.
- Discussions and Wiki are disabled (except `hapax-constitution` Wiki, which mirrors the axiom registry).
- Sponsorships are disabled.
- This file is rendered from `hapax-constitution/sdlc/render/`; edits are overwritten on next render.

## If you are reading this because you found a bug

Hapax is a research apparatus, not a product. Bug reports are not actionable through this surface. The codebase is published for citation and reproducibility, not for use.

## Citation

If your research engages with this codebase, cite via `CITATION.cff` (Citation File Format v1.2.0). Archival DOI lives in `.zenodo.json`. The constellation graph is queryable via DataCite Commons (GraphQL: https://api.datacite.org/graphql).
